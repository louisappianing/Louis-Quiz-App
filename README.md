# Louis Quiz App

#Countries and their capital cities quiz application built with Python.

## About
A fun and educational quiz game that tests your knowledge of the world capitals across all continents.

## Features
- 30 questions across 5 continents (5 countries from each continent)
- Multiple choice questions (A, B, C)
- Score tracking
- Timer
- Grading system (A, B, C, D, F)
- Replay feature

## How To Run
1. Make sure Python is installed
2. Clone this repository
3. Run the command below:
python quiz_app.py

## Built With
- Python 3
- Loops, Conditions and Functions
